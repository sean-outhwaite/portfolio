Clicker

A cross-platform auto clicker application. Can capture cursor position to set where you want to click, then alternates clicks between two positions - stopping when the mouse is manually moved or a key is pressed. Click count per position can be configured in the UI, and click timing is randomised within a set range.

I had been spending a bit time using AI to build Backlog, so I wanted a more hands-on project to make sure I wasn't going rusty. It's built in C#, which I had limited experience with before and can be built to run on macOS and Windows.

  • C#
  • .NET 10
  • Avalonia
  • SharpHook
  • XAML

Shoplock

An almost 1:1 replica of the item shop from Valve's game Deadlock. View live item data fetched from the community API and create a build of your desired items.

I really like a lot of the UI and interactions in this game. I wanted to look under the hood to see how Valve does this, so I learnt about their Panorama UI system and did my best to rebuild the shop as a fully front-end app - including animations, and sound effects.
